Project highlights

  • Chronological train / validation / test split, so there is no look-ahead leakage.
  • Scalers fitted on training data only.
  • Models trained offline and loaded for inference; they are never retrained on page load.
  • Missing data is shown as missing, never invented.
  • Passwords hashed, CSRF protection, rate-limited sign-in.
